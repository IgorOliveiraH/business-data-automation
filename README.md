# 📊 Automação de Relatórios de Vendas e Estoque

### 🎯 Objetivo
Script desenvolvido em Python para automatizar a consolidação de planilhas brutas de vendas e estoque. O objetivo é eliminar o trabalho manual de limpeza e agrupamento de dados no Excel, economizando horas semanais da operação e reduzindo erros humanos.

### 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Bibliotecas:** Pandas, Datetime

### ⚙️ Funcionalidades
1. Ingestão de dados brutos (formato `.csv`) extraídos de sistemas ERP ou plataformas de e-commerce.
2. Limpeza automatizada de registros nulos ou corrompidos.
3. Cálculo de métricas agregadas (Quantidade Total Vendida e Faturamento por Produto).
4. Exportação direta para um relatório estruturado em `.xlsx`, pronto para tomada de decisão pela equipe de negócios.
